# 账号锁定与权限重置

> 演示语料：处理时限与审批人按本地评测环境自洽，不代表任何真实公司制度。

## 账号被锁定

连续 5 次密码错误会锁定域账号 30 分钟。锁定期间所有依赖域账号的系统（内网门户、邮箱、VPN）
都会一起失败，这是同一故障而不是多个问题。

自助路径：

1. 在 intranet 门户「账号自助」页用备用邮箱验证码解锁，解锁后立即修改密码。
2. 手机上装过企业 Authenticator 的，可直接走 App 内的「解锁并重设密码」。

## 什么时候必须找管理员

- 自助解锁入口提示「该账号已被安全策略冻结」：冻结与锁定不同，冻结只能由账号管理员在服务台处理。
- 锁定伴随异常登录提醒（异地/陌生设备）：先建单，安全组要留痕，不要自行改密了事。
- 离职返聘或工号变更后的账号：需要重建而不是解锁。

## 权限开通与变更

权限按「申请人 → 直属主管 → 系统 Owner」两级审批，服务台只受理已获批准的申请。
典型时限：普通系统 1 个工作日，财务与生产环境 3 个工作日。

变更单被驳回最常见的原因是「审批人不是该系统的 Owner」，可在内网门户的系统页查看 Owner 名单。

## 建单时要提供的信息

域账号、锁定发生的时间、自助解锁时的提示原文、是否伴随异常登录提醒。缺时间或缺提示原文会
被退回补充，往返通常多花一个工作日。
