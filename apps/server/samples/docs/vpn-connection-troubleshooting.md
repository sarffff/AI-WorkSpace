# VPN 连接与排障

> 演示语料：其中的地址、错误码与联系方式按本地评测环境自洽，不代表任何真实公司制度。

## 首次连接

1. 在办公电脑安装 VPN 客户端（企业软件中心搜索 "VPN Client"，版本需 ≥ 5.2）。
2. 网关地址填 `vpn.corp.example.com`，账号使用域账号，验证码走企业邮箱。
3. 连接成功后内网网段为 `10.20.0.0/16`，若访问内部系统仍超时，先关闭浏览器的 DoH 再重试。

## 连不上时的排查顺序

1. **客户端版本过旧**：5.2 以下的版本在新网关证书下会握手失败，重装到最新版即可。
2. **网关地址被改过**：设置里确认是 `vpn.corp.example.com`，手工填旧地址是最常见的原因。
3. **域账号密码近期改过**：VPN 复用域密码，改密后需在 intranet 门户重新登录一次以同步。
4. **本地时间偏差过大**：证书校验要求时钟误差在 5 分钟内，长期不关机的笔记本容易漂移。

## 常见错误码

| 错误码 | 含义                       | 自助处理                                             |
| ------ | -------------------------- | ---------------------------------------------------- |
| 7894   | 用户名或密码错误           | 确认用域账号而非邮箱别名                             |
| 7890   | 网关不可达                 | 换网络（手机热点）试一次，用于定位是链路还是账号问题 |
| 8004   | 客户端与系统证书存储不同步 | 需重装客户端，重装无效则属硬件/系统级故障            |
| 442    | 二次验证码失效             | 检查系统时间，再重新发一次验证码                     |

## 什么时候要找人

错误码 8004 重装后仍复现、或同一台电脑出现"连上但内网全部超时"，属客户端之外的故障，
需要 IT 服务台建单由网络组介入（提供：错误码、复现时间、换网络后的表现）。
